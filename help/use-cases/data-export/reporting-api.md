# Reporting API

This article outlines how the [!DNL Customer Journey Analytics Reporting API] can be used to implement the following [data export use case](overview.md):

- Custom application integration

## Introduction

The [!DNL Customer Journey Analytics Reporting API] lets you retrieve the same processed dimensions and metrics available in Analysis Workspace, programmatically. Use the [!DNL Reporting API] to power custom applications, embed reporting in internal tools, or automate the retrieval of Customer Journey Analytics data without a manual export.

## More information

The [!DNL Reporting API] uses the same request and response format as the [!DNL Adobe Analytics] [!DNL Reporting API], but uses a different endpoint. If you're migrating reporting integrations from [!DNL Adobe Analytics], see the migration workflow in the [Quick start guide](/help/getting-started/cja-getting-started.md) for more information.

For authentication, available endpoints, and current request limits, see the [Customer Journey Analytics API documentation](https://developer.adobe.com/cja-apis/docs/).
